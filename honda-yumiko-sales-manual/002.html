成功例と改善のポイント

次回の個別相談で再現する行動を、場面別に整理した資料です。

本案件は個別のセールスマニュアルがないため、田中祐一式の17ステップマニュアルを適用する。

現在のセールスデータ概況（2026-09-16時点）

  • 対象録画: 8件 / 書き起こし: 8件 / 個別分析: 8件
  • 管理シート・決済シート: 未提供。数値は録画内と依頼情報ベース
  • 録画内申込操作3件、セルフスタディ1件、保留3件、非成約1件
  • 確定入金ベースの成約率は算出しない

1. この資料の使い方

面談前に「顧客の危機タイプ」と「支払適格」を確認し、前半の質問と終盤の提案をつなぐ。

2. 場面別の実践例

離婚宣告直後

  • 状態: 理由を聞き続け、追うほど距離が開く。
  • 対応: 今日やめる行動を一つ決める。
  • 再現手順: 現状 → 夫が嫌がる行動 → 代替行動 → 24時間の実践。

不倫後の反芻

  • 状態: 夫は謝罪済みでも本人の時間が止まっている。
  • 対応: 許す／許さないの二択ではなく、反芻が本人の生活へ与える影響を言語化する。

価格提示

  • 状態: 内容へ共感しても、50万円と結果不安で止まる。
  • 改善: 価格前に予算、同意者、他支出、段階商品の適合を確認する。

保留

  • 状態: 当日限定による焦りと、後悔したくない気持ちが衝突する。
  • 改善: 判断材料と再連絡時刻を合意し、断る自由も明示する。

自分にお金を使えない

  • 状態: 家族には使えるが、自分の学びには罪悪感が出る。
  • 対応: 感情的なブロックと、実際の家計制約を分ける。
  • 再現手順: 希望 → 現実予算 → 同意者 → 代替商品。
  • 注意: 「ブロック」と決めつけて、資金不足を心理問題へ置き換えない。

夫に相談が必要

  • 状態: 商品は受けたいが、夫の同意や資金援助が必要。
  • 対応: 相談を弱さではなく、重要な意思決定プロセスとして扱う。
  • 再現手順: 相談相手 → 伝える事実 → 本人の希望 → 回答期限。
  • 注意: 相談を避ける決済方法へ誘導しない。

法的手続き中

  • 状態: 弁護士費用、裁判、夫との連絡制限がある。
  • 対応: 法律判断と本人の感情整理を分ける。
  • 再現手順: 弁護士確認事項 → 支援可能範囲 → 今回の適否。
  • 注意: 離婚の見通しや夫の本心を断定しない。

3. 17ステップ別の重点

ステップ1〜4

  • 信頼形成は必要だが、雑談と自己紹介を合わせて10分以内にする。
  • 終了時刻と進め方を最初に合意する。

ステップ5〜8

  • 現状、理想、本人が考える原因、真因の順を守る。
  • 真因は一般論ではなく、当日の発話二つ以上と接続する。

ステップ9〜12

  • 解決策を顧客の生活へ当てはめる。
  • 費用、配偶者同意、過去投資を価格前に扱う。
  • 商品説明へ進む明示同意を取る。

ステップ13〜17

  • 実績は近い事例を短く示す。
  • 期間、行動量、連絡可能範囲を明確にする。
  • 価格と規約は一度で追えるようにする。
  • 保留でも次の確認事項と時刻を決める。

4. うまくいく流れ

  1. 危機を本人の言葉で確認する。
  2. 望む日常を具体化する。
  3. 本人が変えられる範囲を合意する。
  4. 今まで変わらなかった理由を整理する。
  5. 個別伴走が必要か、自走型で十分かを判断する。
  6. 支払条件と同意者を確認する。
  7. 商品説明への同意を取る。
  8. 申込・保留・見送りのどれでも次の行動を決める。
