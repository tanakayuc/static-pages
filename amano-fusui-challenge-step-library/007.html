2. 見本にした流れ（1秒収納の第1話）

見本: https://sub.1secstrage.com/p/stpchd1_o （UTAGE上で稼働中のページ）

上から順に「話数の帯 → 見出し → 動画 → 注意書き → 次回予告の帯 → 次へ進む条件の帯 → 動画を見ると表示される質問フォーム → 特商法・プライバシーポリシー → 画面下に固定の公開終了カウントダウン」。

天野さん版で変えた点:

  • 回答特典（見本では著書の朗読音声）は置いていません。天野さん側に用意された特典が無いためです。用意できるなら「次へ進む条件の帯」の前に足せます。
  • 記述で必須にするのは「感想（ひと言で大丈夫です）」だけにし、ほかは選択式にしています。配信で「感想をひと言送ってください」と案内しているので、書く負担を増やさないためです（3-2）。見本の2話目にある「LINEでのお名前」は聞きません。照合はメールアドレスで行います。
  • 第3話は感想フォームを置かず、動画の下に個別説明会ページの本文と申込フォームをそのまま続けています（4章。2026-10-10 田中指示、見本は1秒収納の第3話）。

3-2. 3回のフォームで聞くこと（第1話・第2話・個別説明会）

考え方:

  • 毎回メールアドレスを必須にして、本人を照合する。LINEの表示名は本名と一致しないことが多いので、照合に使わない。配信のリンクには読者ID（?uid=）が付くので、UTAGEではメール欄が入力済みで開く（見本の1秒収納も同じ）。
  • 同じことを2回聞かない。第1話で「悩み」、第2話で「学ぶ目的」、個別説明会で「なぜ申し込んだのか（講座のどこに興味を持ったか・どう活かしたいか）」を聞き、3回分を天野さんが面談前に1人分まとめて読める形にする。
  • 選択式の答えは、UTAGEのタグに使う（配信の出し分けや、面談でのコース診断の手がかりにする）。第1話・第2話はシンプルにし、記述は感想と質問だけ。個別説明会だけは申し込んだ理由が面談の要なので、自由記入を2つ置く（2026-10-10 田中指示）。
