教育の芯は 4→5→6 を貫く一本線。

お悩み  →  勘違い  →  理由  →  真の原因  →  解決策

この線から外れた要素はD1に入れない。9/10で田中が繰り返し指摘したのは、この線が引けていないことだった。

台本全体に効かせる3つのルール

ルール1｜入口ではお説教をしない。ワクワクとファンタジーが先。

「なんかかっこええ世界観で来たのに、もっとわくわくさせた方がいいんじゃないの？っていう風に思う」
「一番最初の出会い頭からさ、ゾンビとか言われても、お前なんだよって話。テンション下がるわ、一発目から」
「新しい可能性、ファンタジーを感じさせてくれっていう」
「入り口からそんな正論言われても、聞く気になれなくない。信頼関係もないのに」

耳の痛い話は途中で入れる。

「ライブ途中とかでね、なんか改めないとだめよねとか、今までのパターン変えないとだめだよねって徐々にね、耳の痛いこと言ってくる、別にいいけど」

ルール2｜正しく説明しようとしない。興味性の高い単語を散りばめる。

「なんか説明がくどくて、ややこしいなっていう」
「興味性の高い単語を散りばめておけばいいんじゃないかなとか思うんですよ」
「すごく堅苦しく説明してきてて、なんか夢がない感じがするんですよね」
「正しく伝えようとしてるんだと思います」「"ちゃんとしなきゃいけない"っていう意識が働いてるのかもしれない」
「こういう女性いたら絶対面倒くさいですよ、コミュニケーション」
「そんなのどうでもいいから、どうなるのか教えてよって」（NORIEの言い直しに田中が同意）

ルール3｜軸は「大和コード」一本。ぼかしたまま押し切る。

「原理原則は、俺の中で大和コードって言葉でなんかいい感じにぼかせそうなんで。全部もう繋がってないからね、もう押し切れそうな気もするんですよね」
「大和コード大和コードだってうるせえわってぐらいまで刷り込んでいくと成約しやすい」
「入り口が前世の覚醒なんだけど、"だから前世の覚醒なんだ"っていう落とし込みがあんまりなかったんじゃないかな」

ブロック1｜オープニング

ねらい: コンセプトを刻む → 再現性を見せる → 他手法を淡々と外す → ワクワクへ着地。

1-1 コンセプトを言い切る

「日本人が忘れてしまった誇りと魂。取り戻すだけで全てが叶った、みたいな感じで」

  • 説明を足さない。ここでは「何をする講座か」を一撃で置くだけ。
  • 「大和コード」はこのブロックで初出させ、以後すべてのブロックで戻す。

1-2 再現性を見せる（ケースを3本並べる）

「ケースは、なんか2,000万上がった。ケース2みたいな、パートナー復縁できた。これ出世できたみたいな」

内容 補足
ケース1 売上が2,000万上がった 9/10当日、NORIEから「午前中のグルコンで2,000万売上が上がって喜んでました」と実話の報告あり
ケース2 パートナーと復縁できた
ケース3 出世できた
  • ここでは中身・理屈を言わない。「こうなった」の事実だけを連射する。
  • スケールは上げてよい。田中は「もうちょっとスケールを上げて」というNORIEの発言をそのまま肯定している。

このブロックのNG判定

「こんなこと言われても知らんがなっていう感じの文章になってるから」
「中身の話してなくないっすか？」

→ 抽象的な効能（「本当の自分を生きられる」等）だけが並んでいる状態がこれ。ケースは必ず「誰が・何が・どうなった」で言う。

1-3 他の手法を淡々と否定する

ここでは深掘りせず、名前を並べて外していく。理由はブロック5で回収する。

「いろんな講座も受けた。ヒーリングも学んだ。エネルギーのコントロールも学んだ。書き換えも学んだ」
「でも、なんでか自分の人生に自信がないっていう」

使える表現の型（田中が他案件で使っているもの）:

「ちょっといいけど、ちょっと足りないっていう表現してましたけどね」

1-4 ワクワクへ着地する

「もっとストーリーっぽく書くとか。"もう初めて叶う"とかみたいな。"そんな方法があったらどうしますか？"みたいな」

  • 「全く新しいアプローチで、日本人の誇りと自信を取り戻す」という宣言をここで置く。
  • 締めは疑問形（「そんな方法があったらどうしますか？」）で、答えを本編に預ける。

ブロック1で埋まっていないもの

  • 参加ルール・アウトプットの重要性の伝達は、9/10では触れられていない。

ブロック2｜自己紹介（権威性の確立）

ねらい: 「なぜこの人から聞くのか」を成立させる。来歴の物語はここでは語らない（ブロック8のストーリーで使う）。ここは実績と独自性だけを短く置く。

2-1 独自性を言い切る

「私しかできない独自の大和コード特定セッション」
「このセッションは三つの扉を開けることしかできないと、私しかできませんと」
「今までそんなにちゃんと奥まで深くナビゲートされた人はいましたか、と。いないんですよ、と」

  • この3行は9/10では解決策の文脈で出てきたもの。枕言葉として反復する方針なので、自己紹介とブロック6の両方で打ってよい。

2-2 「私も同じ場所にいた」は一言だけ置く

「みんな忘れてると。私も忘れてたと。大和や、と」

  • ここでは一言に留める。掘り下げはブロック8。

ブロック2で埋まっていないもの

  • 数字の実績（年数・セッション人数・受講生数・メディア等）は9/10では一切出ていない。 ここはNORIEさん側で記入が必要。

ブロック3｜世の中の事象（2つ）

ねらい: 「なぜ我々はこれだけ学んでいるのに幸せになれないのか」を、社会の側と本人の側の2面から語る。

3-a 社会的に、なぜそうなってしまうのか

「結局なんかいろいろ学ぶことが不安感を増幅させるんですよ」
「あんなことも学んで、そんなことも学んで、振り回される人生になっていって、自分の人生は生きられないんですよ」
「いろんな講座のチャンネルもある」

そして「西洋由来のものが入ってきた」という時代の流れに接続する。

「西洋のスピリチュアルとかそういったものじゃなくて、本当の自分、もともとの自分たちの力と才能」

構図としてはこう置く:

学びの選択肢が溢れた  →  学ぶほど不安が増える  →  自分の人生が生きられない

3-b 見込み客自身が、なぜそうなってしまうのか

「忘れた／なくした」の4パターンを並べて、全員を当事者にする。

「忘れてなくしてると」
「親からの遺伝でもう引き継いで、生まれた時からもう持ってない人もいるし」
「無くしちゃう人もいるし」
「学校教育の中で外れていく人もいるし」
「いろんな外れ方があります、っていう」

3-c ここで立てる問い

「なんでね、すごく幸福感に満ち溢れながら、とんとん拍子でうまくいく人っているの？っていう」

→ この問いの答えを、ブロック5の真の原因で回収する。

ブロック3で埋まっていないもの

  • 3-a の社会側は9/10では「学びが溢れて不安が増える」しか出ていない。データ・統計・時代背景の補強が必要（このままだと3-bに比べて弱い）。

ブロック4｜お悩みと勘違い

ねらい: 「いつまで経ってもこの状態のまま、苦しくないですか？」を刺して、次に「それを解決しようとしてこうしますよね」という勘違いを置く。

4-1 お悩み — 問いを連打する

「私と出会った時はこういう風に悩んでて、何度もこの人生は繰り返されている、この輪廻が抜け出せない、といった声を思い出せば」
「ずっと繰り返し続けるパターンないですか？って」

そのまま以下を連打する。

「なんで私っていつもこうなるの？とか」
「何で周りの人がうまくいってるのに私だけこうなの？とか」
「何を学んでも、その時は良くなるけれども、結局元に戻っちゃうとか」
「本当の自分って何なの？」
「ずっと思ってません？みたいな」

日常レベルの言い方も混ぜる。

「私はいつもなんか男に恵まれてないとか、上司に恵まれてないとか」

4-2 勘違い — 「だからこうしますよね」

「もういろんな事を学んで少しは良くなると思うけど、全部テクニックで、ど真ん中じゃないんですよ」
「ほら、もういろんな事に振り回される人生もやめた方が良くないですか？って」

勘違いの中身は、1-3で並べたものをここで再登場させる（ヒーリング／リーディング／クリアリング／エネルギーのコントロール／書き換え／チャクラ／言霊）。

「パワーが出る魔法ありませんか？言葉遣いを、言霊を、とか」

ここが勘違いのピーク。「それをやれば変われると思っていた」という状態を、本人の口から言わせるつもりで書く。

ブロック5｜理由と真の原因

ねらい: 「なぜそれでは上手くいかないのか」をコツコツ積み、最後に真の原因を一撃で言う。

5-1 理由をコツコツ積む

理由①｜どれも「ちょっと足りない」

「じゃあなんでヒーリングでは変われないのか、リーディングでは変われないのか、クリアリングでは変われないのか」
「これはもう全部、欠けてるものがある」
「ちょっといいけど、ちょっと足りない」

理由②｜続かない

「あとはまあ継続ができないとかね。"すごいハーブジュースを毎日飲みましょう"みたいな」
「毎日続けられる。そして全部をカバーすることができるみたいなね」

理由③｜土台をやっていない（最重要のたとえ）

「その根本的なアプローチは、やっぱりその土台からやらないと」
「みんなはなんか表面の家ばっかりペンキ塗って、綺麗になったって言ってるけど、根本的な土台の部分が変わってないから、いつまで経ってもやっぱまたこのパターン出てきたっていう風に、時間が経つにつれてボロが出る」

理由④｜土台がないまま技をやっても空回りする

「この状態でエネルギーワークとか、目を開くとか、第四のチャクラとかやったって、かすっかすのガス欠やんみたいな」
「繋がってない状態で何かを願って、悪い方にしか働かないに決まっとるやんけ、みたいな」
「明らかに繋がってない人達やん、ふわふわふわーってして」

5-2 真の原因をズバッと言う

「日本人が大和コードを忘れてしまっていたからです」
「大和コードだけあれば、人生はすべて変わります」

回収の形:

「その違いは、記憶にありまっせっていう話で。魂の記憶にありました、って。それが埋められたものが大和コードで、三つの扉を開かないと取り戻せません、って」
「シンプルでいいんじゃないの？」

言い切りの型:

「いやいやいや、自分がまだ繋がってないんだよ、歴史と」
「日本人の受け継がれてきたパワーも扱えていないし、自分自身のパワーも扱えていない」
「全部テクニックで、ど真ん中じゃないんですよ。大和コードなんですよ。それ以外ないんだ」

5-3 原因から解決策へのブリッジ

「そもそもそういうテクニックみたいなものとか、そういったものに魅力を感じる意識の使い方みたいなのじゃなくて、本当に日本人が連なってきた歴史の中で脈々と紡がれてきた、この歴史の思いから自分を繋げる、っていう根本的なことからやってった方が絶対にパワーが出ますよ」
「過去からずっと受け継がれてきたものがあって、それが大切にされたものがあって、日本って本当に素晴らしいなって思いもありつつ、かつ自分の良さもそこに乗っけて独自性が出ることによって、もうすごいパワーが出てくる」

ブロック6｜解決策

ねらい: 大和コード＝唯一の解であることを構造で宣言し、証拠を1本語り、その場で第一の扉を体感させる。

6-1 構造を宣言する（これが解決策の背骨）

「まず根本的に大和コードと繋がらない限りは、何も変わらないっていう構造でずっといけばいいんじゃないんですかね？」
「それが、より繋がりが強化になるためのワークとか、自分の能力を引き出すためのワークとか、引き寄せが起きるためのワークとか、そういう秘儀がたくさんあるんですよっていうふうにやっていけばいい」

大和コードと繋がる（必須・唯一）
    └ その上に秘儀・ワークが乗る（強化・拡張）

6-2 証拠を1本だけ、情景描写で語る

田中が名指しした臨場感のテクニックは2つ。

「お客様の声を自分で喋ったときに、臨場感を上げるテクニックは、情景描写をすることです」
「情景描写をすることと、会話が呼び起こされるように表現することですね」

前半（出会い）

「季節は秋。今は雨が降っている。そんな時に私はクライアントと品川駅の18番線で話をしていました、みたいな」
「この秋の風が吹くビュービューの中で、お互いコーヒー飲みながら"寒い寒いね"って言いながら。"でも先生、私はずっと何年も何年も、いつも同じパターンで、最後つかめそうって時にはしごを外されてしまうんです"って。っていうクライアントさんがいたんですよ、っていうような感じで」

中盤（何をしたのか）

「私は後日その人のセッションをしました。私しかできない独自の大和コード特定セッションで、切れた魂をつなぎつつ、その人の本質を見つけつつ、どう生きたいのかを固める、っていうのをやりましたよと」
「その上でさらに秘儀をやっていく中で、どんどん進化していくっていう、日常の人生を書き換えるっていうワークをやって、それを日々やってもらいました。仲間とも交流してもらいました。元に戻らないようにいろんな対策をしました」

後半（再会）

「半年後、また同じ品川駅のホームで会ってくれましたよと。"先生"みたいな。"もうだいぶ季節変わりましたね"。"でも私は人生すごく変わったの"。"え？何があったの？"みたいな」
「"あなたはあの時にセッションで根本の種を抜かなかったら、一生同じ事を繰り返していた。その時の人生どうなってたと思う？" "すごい怖いです"みたいな」
「"考えられません。いろんなことを学んでたのに、本当に全てが繋がった感じになって、私はこれでいいんだって感覚になって、むしろもっといろいろできるっていう風に、今はすごく思ってるんですよ"」
「"そうよね"って。私、今実は活躍してくださってるカウンセラーなんですよ、みたいな」

6-3 語ったあとに一般化する（順番が肝）

「事例を言った後に一般化するわけ。"でも、これって根本的なところは、日本人が紡いできたそのコード、歴史を繋ぐっていうことをしてこなかったから、いつもこういうことが起きていたってことなんですよ"って、あとから解説するわけですよね」

なぜこの順番か:

「なんかこう"変わった"だけだと感情が動かないので」
「"こういう人がこういう風になりました" "はい、まあその人はそうよね"っていう、自他分離が起きるので」

事例は複数ストックしておく。
