## v0.2の操作
- 45日シート：Day 14を報告すると未報告候補から外れる。相談希望を付けると運営一覧に表示。初回のみ10 T/LTT。
- 毎日の運営：イベントごとの未参加/未確認を判別。根拠付きの出欠修正、担当・期限・対応状況・メモを保存。
- 画面別URL：ハッシュで直接開ける。同じブラウザで入力結果を共有し、再読み込みでも保存。別の人のブラウザとは同期しない。
- 仕様：いただいた方針、デモの提案ルール、要決定事項を区別。既存45日シートの実データとは未接続。

体験の基準日時は2026年10月5日09:00 JSTで固定。初期状態の45日シート未報告者は2人。対象外/休止中と今日の締切前は未報告人数に含めない。実会員データは入力しない。

## 3分の体験手順
1. ホームの公園でアバターを押し、プロフィールとChatworkへの導線を見る。
2. セールスコンサルの「利用を報告」から、実施内容を入力して申請する。
3. 右上の「体験する役割」を「運営者」に変更し、「運営ルーム」で承認する。
4. 840 T → 1,040 T、14,840 LTT → 15,040 LTTへ変化。順位とサポート利用状況も反映。
5. 「ジョブ・着せ替え」で「マグを持たせる」。ホームのアバターにも反映される。
6. 「学びとサポート」で教材を開き、完了すると各30ポイント。二重加算なし。
7. 左下のリセットから体験をやり直せる。

## 主要画面
- ホーム：コミュニティの公園、T/LTT、順位、未利用サポート、全体目標、機能カード。
- 仲間：挑戦内容・得意分野・活動・スタッフ役割のプロフィール。
- 学びとサポート：利用報告、利用済み・承認待ち・対象外、教材の完了チェック。
- 活動：相談、実践、SNS、JV、ファネル、イベント、部活完走・表彰の申請と履歴。
- ジョブ・着せ替え：メイン/サブジョブ、バッジ、マグの獲得と装備。
- 運営ルーム：運営者の承認/差戻し、認定講師・運営サポーターの確認ビュー。
- 田中祐一AI、イベント、3ヶ月チームの導線画面。

## 試作の範囲
配点・閾値は提案値。ブラウザ内だけで動くデモで、データは利用者間で共有されません。役割切替は権限管理の実装ではありません。各活動はデモ上1回のみ申請できます。季節の自動切替、過去データ移行、実際の認定・契約回数管理、発送は未実装。教材動画・Chatwork・田中祐一AI・Kajabi・Supabaseは未接続。実会員情報・チャット原文・認証情報は一切含みません。

本番ではイベントIDによる二重加算防止、実施と予約/消化の区別、対象外の除外、サーバー側の認証と監査履歴が必要です。履歴の移植日時を行動日時とみなさず、過去実績の加算先はLTTに限定します。

## 実行
このフォルダで `python3 -m http.server 18765` を実行し、http://127.0.0.1:18765/ を開きます。このURLは同じPC限定。

動画はCloudflare公式の公開サンプル（PLC教材ではない）でPlayer APIに接続。実会員・本番教材・サーバー判定は未接続。10分の判定テストで69%・70%・末尾シーク・重複を再現できます。SNSボタンは投稿画面まで。投稿は本人が行い、クリックだけでは加点しません。学びの申請とデモ承認を分離しています。在籍区間は簡略計算で、2026/10/6を基準に休止日数を控除。89/90日、364/365日で解放条件を検証。

`node test-journey.cjs`：ログアウトと失効、停止会員、トークン更新、視聴の和集合、シーク・非表示除外、70%境界、二重付与防止、アウトプット承認、在籍解放。実MCPのOAuth・失効確認は別途必要。資料のFB公式ページは取得制限により本文確認できず、共有画面の端末検証が残ります。本番停止・移行・投稿は実行していません。

ローカル検証：3D建物のクリックで学習室へ入室。Cloudflare公開サンプルの実再生が99%に達し、+30を確認。判定テストで末尾シーク0%、69%未付与、70%一度のみ付与、アウトプットの申請→承認で+20を確認。MCP認可→ポータルのみログアウト後の利用成功→接続解除後の拒否を操作確認。在籍89日未解放と公開設定による非表示を確認。PC/390pxの3D・2D表示を検品。
