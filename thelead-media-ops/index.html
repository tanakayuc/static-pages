スタッフの手順

YouTubeの公開

  1. Studioの「コンテンツ」を開く
  2. 公開する動画にチェックを入れる
  3. 「編集」から「公開設定」を「公開」にして更新
  4. 公開後に、動画のURLを開いてサムネと題が正しいかを確かめる

メルマガの配信（UTAGE）

  1. 配信先は「【ザ・リード】マガジン」
  2. 左メニューの「予約中」から下書きを開く
  3. テスト送信で自分宛に届くか見る
  4. 送信のタイミングを決める
  5. ステータスを「稼働中」にして保存

Instagram・Facebookページ

  1. 投稿表の本文と素材を開く
  2. Meta Business Suiteで予約を入れる
  3. Facebookはリンクを1件目のコメントに入れる
  4. 入れ終わったら投稿表に日時を書く
UTAGEは、送信のタイミングが「今すぐ」のままステータスを「稼働中」にして保存すると、すぐに全員への配信が始まります。止められない前提で、保存の前に宛先と内容を確かめてください。

編集の標準（田中さんの動画）

  • 全体を1.15倍で仕上げる
  • 話し始めの「はい」はテロップに出さない
  • カードの図解は、全部の行を同じ太さにして、文字を枠の内側に収める
  • YouTubeショートは本編への誘導の形。Instagramリールは専用に作る（上部の黒帯に題を大きく。本編への誘導の枠は付けない）
